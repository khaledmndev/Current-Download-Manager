# Contributing

This is proprietary source, not an open-source grant. Obtain the maintainer's
permission before submitting patches; no contributor license or rights transfer
is implied. Issues may describe reproducible bugs without private URLs or data.

Run the checks in README.md. Keep tests isolated with CURRENT_DATA_DIR. Never
commit runtime downloads, local databases, personal browser captures, copied
third-party app code or credentials. Run scripts/check-public.py before staging.
