# Security reports

Do not open public issues containing credentials, private download URLs,
cookies, browser profiles, databases or personal screenshots.

After this repository is hosted, use GitHub's private vulnerability reporting
when the maintainer has enabled it. If it is unavailable, open a minimal issue
requesting a private reporting channel without posting exploit details or data.
The maintainer must enable private reporting before inviting sensitive reports.

This is an unsigned alpha. Security audits and a production support policy have
not been completed. No response-time commitment is currently offered.
